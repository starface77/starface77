# Doniyor

Founder of **Sharrowkin**, an AI coding app that remembers your project. Built with **Nare Labs** in Uzbekistan.

[sharrowkin.dev](https://www.sharrowkin.dev) · research at [@narelabs](https://github.com/narelabs)

### Sharrowkin

A desktop app where the AI agent Kins writes, runs and checks code on your own computer and keeps the memory of your project between sessions: what was decided, what broke, what the code looks like.
